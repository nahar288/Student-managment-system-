# Bupali Bank Management System

The Bupali Bank Management System is a simple banking application designed to manage basic bank account operations. It allows users to create accounts and perform common banking transactions in an organized way.

📌 Project Overview

This project demonstrates how a basic bank management system works using programming concepts such as classes, objects, methods, encapsulation, and user input.

The system provides a simple menu where users can select different banking operations.

✨ Features
Create a new bank account
Store account number and account holder information
Check account balance
Deposit money
Withdraw money
Validate deposit and withdrawal amounts
Display account information
Menu-based transaction system
🛠️ Technologies Used
Python
Object-Oriented Programming (OOP)
Git
GitHub
📂 Main Concepts Used

1. Class and Object

The system uses a BankAccount class to represent a bank account.

1. Encapsulation

Account information such as the balance is managed through methods that control how the data is accessed and modified.

1. Methods

Different methods are used for operations such as:

Deposit
Withdraw
Check balance
4. User Input

Users can interact with the system by selecting options from the menu and entering the required information.

🏦 Example Operations

The user can choose from options such as:

1. Create Account
2. Deposit Money
3. Withdraw Money
4. Check Balance
5. Exit
🎯 Project Goal

The main goal of this project is to build a simple banking system while practicing Python programming and Object-Oriented Programming concepts.
